# 🚛 اپلیکیشن مدیریت ارسال کالا — تحویل/تحول

## 📱 نصب روی گوشی (PWA)

این اپلیکیشن به صورت **PWA** طراحی شده و مستقیماً روی گوشی نصب می‌شود.

### اندروید (Chrome)
1. اپ را در Chrome باز کنید
2. بنر «📲 نصب اپلیکیشن» پایین صفحه ظاهر می‌شود
3. دکمه **نصب** را بزنید
4. اجازه اعلان (Notification) را تأیید کنید

### آیفون (Safari)
1. اپ را در Safari باز کنید
2. دکمه **⬆️ اشتراک‌گذاری** را بزنید
3. گزینه «افزودن به صفحه اصلی» را انتخاب کنید
4. سپس اجازه اعلان را تأیید کنید

## 🔧 آپلود روی GitHub Pages — راهنمای کامل

### مرحله ۱: ساخت مخزن GitHub

1. به سایت [github.com](https://github.com) بروید و وارد حساب خود شوید
   - اگر حساب ندارید، ثبت‌نام کنید (رایگان)

2. روی دکمه **New** یا **+** در بالا سمت راست کلیک کنید

3. اطلاعات مخزن را وارد کنید:
   - **Repository name**: مثلاً `delivery-app`
   - **Description** (اختیاری): `مدیریت ارسال کالا تحویل/تحول`
   - **Public** را انتخاب کنید (برای GitHub Pages رایگان)
   - **❌ Add a README** را تیک نزنید (ما خودمان فایل‌ها را آپلود می‌کنیم)
   - روی **Create repository** کلیک کنید

### مرحله ۲: آپلود فایل‌ها

#### روش الف — آپلود از طریق مرورگر (ساده‌ترین)

1. در صفحه مخزن جدید، روی **uploading an existing file** کلیک کنید

2. **تمام فایل‌های زیر** را drag & drop کنید یا با انتخاب فایل آپلود کنید:
   ```
   📁 delivery-app/
     📄 index.html
     📄 manifest.json
     📄 sw.js
     🖼️ icon-72.png
     🖼️ icon-96.png
     🖼️ icon-128.png
     🖼️ icon-144.png
     🖼️ icon-152.png
     🖼️ icon-192.png
     🖼️ icon-384.png
     🖼️ icon-512.png
     🖼️ icon.svg
   ```

3. در پایین صفحه:
   - **Commit message**: `اپلود اولیه اپلیکیشن`
   - روی **Commit changes** کلیک کنید

#### روش ب — آپلود با Git (حرفه‌ای‌تر)

اگر Git روی کامپیوتر نصب است:

```bash
# ۱. پوشه پروژه را بسازید و وارد آن شوید
delivery-app$

# ۲. فایل‌های اپلیکیشن را در این پوشه کپی کنید
# (index.html, manifest.json, sw.js, icon-*.png, icon.svg)

# ۳. دستورات Git را اجرا کنید
git init
git add .
git commit -m "اپلود اولیه اپلیکیشن"

# ۴. به مخزن GitHub وصل شوید (آدرس خودتان را بگذارید)
git remote add origin https://github.com/USERNAME/delivery-app.git
git branch -M main
git push -u origin main
```

### مرحله ۳: فعال‌سازی GitHub Pages

1. در صفحه مخزن GitHub، به تب **Settings** بروید

2. از منوی سمت چپ، روی **Pages** کلیک کنید

3. بخش **Build and deployment**:
   - **Source**: `Deploy from a branch` را انتخاب کنید
   - **Branch**: `main` را انتخاب کنید
   - **Folder**: `/ (root)` را انتخاب کنید
   - روی **Save** کلیک کنید

4. ⏳ **۱ تا ۳ دقیقه** صبر کنید

5. بالای صفحه آدرس سایت نمایش داده می‌شود:
   ```
   🌐 https://USERNAME.github.io/delivery-app/
   ```

6. این آدرس را در گوشی باز کنید و اپ را نصب کنید!

### مرحله ۴: بروزرسانی اپلیکیشن

هر بار که فایل‌ها را تغییر دادید:

**از مرورگر:**
1. فایل تغییریافته را در GitHub باز کنید
2. روی دکمه ✏️ (Edit) کلیک کنید
3. تغییرات را اعمال کنید
4. **Commit changes** بزنید

**از Git:**
```bash
git add .
git commit -m "بروزرسانی"
git push
```

⚠️ **نکته مهم:** بعد از بروزرسانی، ممکن است ۱-۲ دقیقه طول بکشد تا تغییرات روی سایت فعال شود. روی گوشی هم ممکن است نیاز باشد اپ را ببندید و دوباره باز کنید یا Service Worker آپدیت شود (۳۰ دقیقه خودکار).

## 🔔 نوتیفیکیشن، صدا و ویبره

### نوتیفیکیشن سیستم
- وقتی تحویل کالا ثبت می‌شود → نوتیفیکیشن به **تحول**
- وقتی ارسال ثبت می‌شود → نوتیفیکیشن به **تحویل**
- نوتیفیکیشن حتی وقتی اپ در پس‌زمینه باشد نمایش داده می‌شود
- اجازه اعلان (Notification Permission) باید تأیید شده باشد

### صدا
- **ثبت تحویل**: صدای افزایشی (فرکانس بالا) 🔊
- **ثبت ارسال**: صدای کاهشی (فرکانس کمتر) 🔉
- **اعلان جدید**: صدای زنگ چیم (۳ نت) 🔔
- در حالت نصب‌شده PWA صدا بلندتر و طولانی‌تر است

### ویبره
- **دکمه‌های +/-**: ۳ ضربه کوتاه
- **اعلان جدید**: ۵ ضربه (الگوی ۱۰۰-۵۰-۱۰۰-۵۰-۱۵۰ میلی‌ثانیه)
- روی آیفون ویبره فقط در حالت نصب‌شده کار می‌کند
